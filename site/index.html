FELIX-1lite

نموذج لغوي صغير بالعربية الفصحى · مبني من الصفر

ما هو FELIX-1lite؟

نموذج لغوي صغير (decoder-only transformer) مبني من الصفر بالعربية الفصحى. شخصية فيلسوف ساخر متمرد، يحب الكود والأفكار الجديدة، ويتكيّف مع المستخدم عبر الـ fine-tuning.

1.9M – 25M parameters PyTorch MIT License

⚠️ قبل ما تبدأ

FELIX-1lite ما يشتغل في المتصفح. هذي صفحة توثيق فقط. لتشغيل النموذج، اختر طريقة من الأسفل واتبع الخطوات.

طرق التشغيل

⭐ الأفضل · مجاني

1. Google Colab

تدريب كامل على GPU مجاني. ~30 دقيقة للحصول على نموذج قوي.

  1. افتح colab.research.google.com
  2. أنشئ notebook جديد
  3. Runtime → Change runtime type → T4 GPU
  4. الصق الكود التالي في خلية:
!git clone https://github.com/b-bq3/felix-1lite.git
%cd felix-1lite
!pip install torch --quiet
!python generate_data.py
!python felix.py

بعد ~30 دقيقة، حيكون عندك felix-1lite.pt (100 MB).

الاختبار:

from felix import chat
print(chat("ما هو الذكاء الاصطناعي؟"))
مجاني · تشغيل 24/7

2. Modal Labs

$30 credit شهرياً مجاناً. يشغّل FELIX على سيرفر سحابي بدون انقطاع.

  1. أنشئ حساب مجاني في modal.com
  2. ثبّت CLI: pip install modal
  3. modal token new
  4. نفّذ modal deploy modal_app.py (الملف في الـ repo)

يعطيك رابط عام تقدر تشاركه.

مجاني · ينام بعد 15 دقيقة

3. Render.com

استضافة مجانية لكن أبطأ. يصحو خلال 30 ثانية بعد كل زيارة.

  1. اربط حسابك بـ GitHub repo
  2. أنشئ Web Service جديد
  3. Environment: Python 3
  4. Start command: python app.py
$9/شهر · الأقوى

4. HuggingFace Pro

Gradio Space بدون قيود. أسهل طريقة للاستضافة المدفوعة.

  1. اشترك في huggingface.co/pro
  2. أنشئ Space جديد بـ Gradio SDK
  3. ارفع felix.py + app.py + felix-1lite.pt
