# FELIX-1lite 🤖

نموذج لغوي صغير (~25M parameters) بالعربية الفصحى، مبني من الصفر بدون أي نموذج جاهز.

## المميزات
- ✅ محادثة عامة
- ✅ توليد أكواد (Python, JavaScript)
- ✅ أفكار إبداعية
- ✅ شخصية فيلسوف ساخر متمرد
- ✅ شخصية قابلة للتكيّف مع المستخدم

## الملفات
- `felix.py` — النموذج + التدريب + الاستدلال
- `app.py` — واجهة Gradio
- `generate_data.py` — توليد بيانات FELIX
- `felix_data.txt` — بيانات التدريب الأولية
- `felix-1lite.pt` — الـ weights (يُولَّد بعد التدريب)

## للباحثين
الكود مكتوب بـ PyTorch خالص. يمكن قراءته، تعديله، أو بناء نسخة أكبر عليه.
